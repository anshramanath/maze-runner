# 🎮 Maze Runner

A simple browser-based maze game where the player navigates through a maze to reach the bed.

## 🌐 Live Demo

https://anshramanath.github.io/Maze-Runner

---

## ✨ Features

- 10x10 maze grid
- Wall collision detection
- Move counter
- Win condition
- Interactive UI

---

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- Python

---

## 📂 Project Structure

```text
maze-runner/
├── index.html
├── main.js
├── style.css
└── grid.py
```

---

## 🚀 Running Locally

```bash
git clone https://github.com/anshramanath/maze-runner.git
cd maze-runner
```

Open `index.html` in your browser.
